# Interdrogas — Farmácia com Manipulação

Projeto acadêmico de landing page institucional para uma farmácia de manipulação fictícia.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3 puro
- Flexbox e CSS Grid
- Media Queries para responsividade
- JavaScript para menu mobile e validação do formulário
- Imagens em SVG

## Estrutura

```text
projeto-web/
├── index.html
├── pages/
│   ├── sobre.html
│   ├── servicos.html
│   └── contato.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/
│   ├── farmacia.svg
│   ├── produto-1.svg
│   ├── produto-2.svg
│   └── produto-3.svg
└── README.md
```

## Responsividade

O layout foi preparado para:
- Desktop: 1200px ou mais
- Tablet: aproximadamente 768px
- Mobile: aproximadamente 375px

## Como executar

1. Extraia o arquivo `.zip`.
2. Abra a pasta `projeto-web`.
3. Abra `index.html` em um navegador.
4. Para uma experiência melhor, pode utilizar uma extensão de servidor local no VS Code, como Live Server.

## Observação

Os dados de endereço, telefone, horário e conteúdo de produtos são ilustrativos e devem ser substituídos caso o projeto exija informações reais.
